🔑 Hilfe zur Anmeldung

1. Wo finde ich meinen 6-stelligen PIN?
Dein PIN entspricht deiner persönlichen SSV-Adressnummer. Du findest ihn auf deinen Einladungen zur Generalversammlung, im Schützen-Ausweis oder Lizenzbüchlein.
2. PIN vergessen oder nicht zur Hand?
Klicke einfach auf «PIN vergessen? Code per Mail». Du kannst deinen Namen eingeben und dir einen sicheren Einmalcode an deine hinterlegte E-Mail-Adresse senden lassen.
3. E-Mail-Adresse auch nicht bekannt?
Gib im Feld einfach deinen Vornamen und Nachnamen ein (z.B. Max Muster). Das System ermittelt deine hinterlegte E-Mail-Adresse automatisch und sendet den Code dorthin.
💡 Noch keine E-Mail im Verein hinterlegt?
Falls für deinen Namen noch keine Adresse registriert ist, wende dich kurz an den Vorstand (z.B. Daniel Hunziker oder Kassier). Wir hinterlegen deine Daten gerne für dich.
